# Event Report: Smart Plushies for Children

### Purpose

Take part in a STEM activity to make smart plush toys, combining programming and sound training to create gifts for children.

### Main Activities

- **Programming:** Program interactive features for the plush toys.
- **Sound training:** Connect the trained sound component with the program to add interaction to the toys.
- **Gifts for children:** Complete the smart plush toys to give to children.

### Takeaways

- Understand how programming and sound can work together in a physical product.
- Products for children need to be easy to use, safe, and suitable for their age.

### My Impressions

This activity combined hands-on STEM work with making something to give to children.
