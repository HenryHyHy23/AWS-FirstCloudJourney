### Week 1 Objectives:

- Understand AWS fundamentals, global infrastructure, pricing, cost management, and support.
- Learn IAM identities, policies, roles, and least privilege.
- Understand VPC networking, security, multi-VPC, and hybrid connectivity.
- Study EC2 instance types, AMIs, storage, backup, and user data.
- Understand instance metadata and temporary credentials for applications.
- Learn CloudShell, basic Linux commands, and AWS CLI usage.

### Week 1 Achievements:

- **AWS fundamentals:** Understood AWS differentiators, Regions/AZs, cost management, and support options.
- **IAM:** Understood users, groups, policies, roles, and least privilege.
- **VPC:** Understood routing, network security, multi-VPC, and hybrid connectivity.

- **Application access:** Understood metadata, IAM Roles, STS, and temporary credentials.
- **CloudShell:** Understood browser-based CLI access, Console permissions, and basic Linux operations.
